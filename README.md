# TaskFlow – Productivity Dashboard

TaskFlow is a simple and beginner-friendly productivity dashboard built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add and manage tasks
- Mark tasks as completed
- Delete tasks
- Productivity timer
- Clean and modern dashboard UI
- Responsive layout
- Interactive JavaScript functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
